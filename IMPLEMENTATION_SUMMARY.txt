HOW TO USE:
═════════════════════════════════════════════════════════════════

1. SWITCHING PERSONALITIES:
   
   a) Click 🎙 (Voice Settings) tab on right sidebar
   b) Use dropdown to select personality
   c) Read description box to understand traits
   d) Start chatting - responses use new personality!
   e) Switch anytime during conversation

2. PERSONALITY OPTIONS:
   
   🎮 QUIRKY (Default)
      Witty, sarcastic, gaming culture vibes
      Best for: Casual sessions, humor, creativity
   
   💼 PROFESSIONAL
      Focused, organized, results-driven
      Best for: Production work, serious problems
   
   🎪 WITTY
      Sharp humor, clever wordplay
      Best for: Learning, understanding concepts
   
   🎓 MENTOR
      Patient, encouraging, growth-focused
      Best for: Learning new skills, confidence building
   
   😎 CHILL
      Laid-back, friendly, stress-reducing
      Best for: Relaxed development, frustration relief
   
   🔬 ANALYTICAL
      Logic-driven, data-oriented, performance-focused
      Best for: Algorithms, optimization, architecture

3. CUSTOMIZING PERSONALITIES:
   
   Edit utils/system_prompts.py:
   
   a) Modify SYSTEM_PROMPTS dictionary
   b) Update PERSONALITY_DESCRIPTIONS
   c) Add to ACCENT_PHRASES
   d) Restart app to apply changes

ADVANCED USAGE:
═════════════════════════════════════════════════════════════════

CREATE CUSTOM PERSONALITIES:

In utils/system_prompts.py:

SYSTEM_PROMPTS = {
    "my_custom": """You are my custom personality...
    [Your custom system prompt here]
    """,
}

PERSONALITY_DESCRIPTIONS = {
    "my_custom": "Your description here",
}

ACCENT_PHRASES = {
    "my_custom": [
        "Phrase 1",
        "Phrase 2",
    ]
}

Then restart app and select in dropdown!

MOOD-BASED PERSONALITY SELECTION:

Create logic like:
```python
MOOD_PERSONALITIES = {
    "frustrated": "chill",
    "focused": "analytical",
    "bored": "quirky",
    "learning": "mentor",
}
```

TESTING-DRIVEN PERSONALITY CHOICE:

Try personalities on same problem:
1. "Explain this in Quirky mode"
2. "Now explain it Analytically"
3. "How would Mentor approach this?"
