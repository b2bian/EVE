INSTALLATION TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════

If tkinter installation fails:
  • Ensure Homebrew is updated: brew update
  • Try: brew install python-tk@3.14 --force
  • Or reinstall Python: brew reinstall python@3.14

If packages won't install:
  • Remove venv: rm -rf venv
  • Recreate: python3 -m venv venv
  • Reactivate: source venv/bin/activate
  • Reinstall: pip install -r requirements.txt

If Ollama connection fails:
  • Check if running: ps aux | grep ollama
  • Restart: ollama serve in new terminal
  • App works fine without Ollama (AI just disabled)
